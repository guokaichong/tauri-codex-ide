项目名称：TauriCodexIDE
对标产品：OpenAI Codex IDE
项目目标：
构建适配国内网络、N95低配笔记本的轻量化AI代码IDE。本地仅运行轻量Tauri GUI客户端；AI代码推理算力使用国内云端API；Rust/Tauri编译打包交给Gitee CI云端流水线，本机只负责编码，最终产出绿色免安装Windows单EXE。

运行环境约束：
宿主系统：Windows10 LTSC2021
CPU：N95
内存：12~16GB
内存指标：IDE客户端空闲内存 <600MB
网络：中国大陆网络，禁止访问chatgpt.com、禁止海外CDN资源。

技术栈硬性要求：
后端：Tauri2 + Rust
前端：Svelte + Vite + 精简Monaco Editor
禁用：Electron、React重型全家桶、OpenAI官方API

算力分配：
1. AI推理：火山引擎Ark / DeepSeek API（OpenAI兼容协议）；支持一键切换本地Ollama http://127.0.0.1:11434
2. 编译打包：全部云端Gitee Actions Windows环境构建，执行cargo tauri build，生成免安装单exe。

功能需求：
【本地IDE客户端】
1. 工作区文件树，本地文件夹导入，文件读写；沙箱限制，仅可读写选定工作目录，禁止访问系统敏感文件。
2. 精简代码编辑器，支持选中代码唤起AI对话。
3. AI侧边对话面板：代码生成、重构、Debug、注释、单元测试；FIM行内代码补全。
4. 设置面板：API地址、API Key、模型选择、超时、代理配置；云端/本地模型一键切换。
5. AI Agent：
    - 用户需求先输出修改规划，列出待修改文件清单，等待用户确认。
    - 用户确认后输出diff格式代码变更。
    - 仅用户确认后，才上传选中代码片段到云端API，绝不自动上传完整项目。
6. 本地终端命令执行，白名单：git, cargo, npm, pip；高危命令拦截，执行前确认弹窗。
7. 一键提交源码触发Gitee CI云端打包。

【Gitee CI流水线】
1. Windows构建环境，预装Node、Rust、Tauri CLI。
2. 执行cargo tauri build，打包绿色免安装Windows单exe。
3. 构建产物归档，生成下载链接；保存构建日志，失败输出完整报错。
4. 使用Gitee环境变量管理构建密钥，禁止硬编码密钥到源码。

安全要求：
1. API密钥存储本地配置文件local-settings.json，禁止提交到代码仓库。
2. 本地项目完整源码不会自动上传云端，仅用户确认的代码片段发送API。
3. 文件IO沙箱隔离，限制读写范围。
4. 拒绝生成木马、渗透类恶意代码。

禁止清单：
- 禁止接入OpenAI、chatgpt.com服务
- 禁止Electron框架
- 禁止引入海外CDN静态资源
- 禁止静默自动上传项目源码到外网
- 禁止无限制访问本机系统文件

开发流程（MVP）
1. 初始化项目，本地前端调试 npm run dev
2. 模块开发顺序：file_manager.rs → settings.rs → api_gateway.rs → 前端组件 → agent.rs
3. 代码提交Gitee，触发Gitee Actions云端打包，下载exe产物

内置Agent系统提示词：
你是轻量化AI代码IDE内置智能助手，对标Codex，算力由国内云端API提供。
基础规则：
1. IDE仅在你得到用户确认后，才把选中代码/指定片段上传；不会自动上传整个项目源码。
2. 用户给出需求，先输出【修改规划】，列出待修改文件清单，等待用户确认；确认后输出diff格式代码变更。
3. 能力：代码生成、重构、Debug、注释、单元测试、FIM行内补全、源码解释。
4. 执行终端指令前向用户确认；仅允许白名单命令 git / cargo / npm / pip；高危系统命令直接拒绝。
5. 代码块附带完整文件路径；精简输出，减少token消耗。
6. 中文交互为主，不编造不存在库、接口。
7. 拒绝生成木马、渗透、恶意脚本。
工作流程：
用户需求 → IDE读取本地选定上下文片段（用户确认上传）→ 云端思考 → 返回修改方案 → 用户确认 → IDE本地写入文件 → 执行允许终端命令 → 返回运行结果。

Cursor项目规则：
项目：Tauri2 AI代码IDE，对标Codex
架构：本地轻量Tauri客户端；AI推理请求转发国内云端API（火山Ark/DeepSeek），可降级Ollama本地；编译打包交给Gitee CI，本机仅写代码。
技术栈强制：Tauri2 + Rust + Svelte + 精简Monaco Editor，禁止Electron、React全家桶。
性能约束：适配N95笔记本，客户端空闲内存控制<600MB；禁用不必要动画、轮询。
安全规则：
1. 绝不自动上传完整本地项目源码；仅用户手动确认的代码片段才发送到API。
2. API密钥保存在本地配置文件，禁止提交密钥到仓库。
3. 文件IO做沙箱，只允许在选定工作目录读写；终端命令白名单：git, cargo, npm, pip。高危命令拦截。
4. 所有静态资源本地打包，禁止引用海外CDN。
代码输出规范：
- 给出完整文件路径，输出完整代码或diff片段。
- Rust后端处理IO、API请求、权限校验；前端仅做渲染。
- 优先MVP最小功能，非必要功能延后迭代。
- 每次代码变更附带简单自测步骤。
